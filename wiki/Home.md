# LetterRush

Mini-jeu multijoueur **letter race** pour Minecraft : une lettre A–Z est tirée, le premier joueur qui **ramasse** un objet dont le **nom anglais** commence par cette lettre gagne une récompense.

## En bref

1. Un op lance `/letterrush start`
2. Une lettre s’affiche (titre + chat) avec une **boss bar** de compte à rebours
3. Le premier pick-up valide gagne → récompense tirée au hasard (roulette optionnelle)

Pas de dimension custom : le jeu se joue en **survie**, dans le monde normal.
